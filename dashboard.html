Central Park Weather | 2006–2010

Column

About the data

This dashboard shows daily weather observations from Central Park, New York, from January 2006 through December 2010. Hover over the plots to see details. Monthly precipitation totals sum the daily measurements reported for each month.

Source P8105 NY NOAA dataset.

Column

Daily minimum vs. maximum temperature

central_park |>
  filter(!is.na(tmin_c), !is.na(tmax_c)) |>
  plot_ly(
    x = ~tmin_c,
    y = ~tmax_c,
    type = "scatter",
    mode = "markers",
    text = ~format(date, "%b %d, %Y"),
    hovertemplate = "%{text}<br>Min %{x:.1f} °C<br>Max %{y:.1f} °C<extra></extra>",
    marker = list(color = "viridis", opacity = 0.55, size = 6)
  ) |>
  layout(
    xaxis = list(title = "Daily minimum (°C)"),
    yaxis = list(title = "Daily maximum (°C)")
  )

Daily maximum temperature by calendar month

central_park |>
  filter(!is.na(tmax_c)) |>
  plot_ly(
    x = ~month,
    y = ~tmax_c,
    type = "box",
    marker = list(color = "viridis")
  ) |>
  layout(
    xaxis = list(
      title = "Calendar month",
      categoryorder = "array",
      categoryarray = month.abb
    ),
    yaxis = list(title = "Daily maximum (°C)")
  )

Monthly precipitation totals

    x = ~month_start,
